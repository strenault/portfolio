Projets et réalisations

Outils PowerShell — parc du CHU de Nantes

  • StressTest_PC (v4.4) : stress matériel CPU/RAM/disque/GPU parallélisé avec étalonnage, scores, détection de goulots d'étranglement, aide à la décision de compatibilité Windows 11. Sans droits administrateur, depuis clé USB.
  • Get-Diagnostic (v2.3) : diagnostic et dépannage (SMART, services critiques, réseau/proxy, BitLocker, WSUS/Intune/GPO), mode réparation assistée avec point de restauration, rapport HTML hiérarchisé pour le support N1/N2.
  • Diag_PC (orchestrateur modulaire) : plateforme en 3 modules — contrôle des applications métiers du SI hospitalier (Office 365, SSO/webmail, Citrix Workspace, magasin applicatif), état de sécurité (EDR, antivirus), rapport HTML A4 nominatif avec historique CSV.
  • Rch Pilote : recherche des pilotes dans la base de données SCCM pour identifier les drivers disponibles des postes du parc.
  • DiagIdentification.psm1 : module commun d'identification des postes, mutualisé entre tous les outils.
